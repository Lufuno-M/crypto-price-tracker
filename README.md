# MarketBrain

MarketBrain is a personal market-context system.

It does not exist to display more information.

It exists to restore the right context at the right time.

## Core model

MarketBrain's fundamental unit is the **Obligation**.

An Obligation represents something the user believes, expects, or is committed to testing against reality.

The model is:

Obligation → Evidence → Confrontation → Resolution

### Ontology

Defines what exists.

- Obligations
- Evidence Observations
- Assets as context
- Pursuit
- Price Gravity
- Status and history

### Resolution

Defines what happened.

Resolution requires actual evidence and explicit evidence references.

Activity is not evidence.

Evidence is not automatically confrontation.

Confrontation is not automatically resolution.

### Ranking

Defines what should be restored first.

Ranking considers:

- direct confrontation
- Price Gravity relevance
- pursuit
- asserted importance
- timeframe relevance
- meaningful neglect
- relevant evidence

Ranking does not determine truth or resolution.

## Model hierarchy

Ontology defines what exists.

Resolution defines what happened.

Ranking defines what should be restored first.

Interface expresses the result.

## Development principle

**Model first. Interface second.**

The interface must remain subordinate to the model.

A model gap must appear in **3 independent cases** before it earns a model-change discussion.

## Status

The canonical MarketBrain model is currently being tested against cases before implementation is built around it.

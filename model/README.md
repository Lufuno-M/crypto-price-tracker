# MarketBrain Model

MarketBrain holds the user's relationship to the market.

The primary entity is the **Obligation**, not the asset.

An Obligation is a commitment with:

- a falsifiable condition
- a mechanism or reasoning
- a timeframe
- an explicit importance
- an explicit invalidation/resolution path

Core model principles:

1. Importance is asserted at creation, not inferred from attention.
2. Avoidance is evidence, not absence.
3. Neglected is reversible; Confirmed and Invalidated are permanent states.
4. Resolution happens by confrontation, not activity.
5. A new entry does not resolve an old obligation unless it explicitly addresses its condition.
6. Resolution must reference actual evidence observations.
7. Pursuit influences restoration ranking, not the underlying truth of an obligation.
8. Price Gravity describes interaction between macro imbalances and liquidity sweeps.
9. The system restores context rather than merely displaying information.
10. A model gap must appear in 3 independent cases before it earns a model-change discussion.
